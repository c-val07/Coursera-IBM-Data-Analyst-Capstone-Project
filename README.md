# Coursera IBM Data Analyst Capstone project

## Overview

In this project, I worked as an Associate Data Analyst at a technology consulting agency, analyzing developer survey data to identify current and emerging technology trends. The goal was to uncover insights into programming languages, databases, platforms, and frameworks that the organization can use to guide strategic technology decisions.

Using SQL, Jupyter Notebook, and IBM Cognos Analytics, I cleaned and analyzed global developer survey data, performed exploratory data analysis (EDA), and built dashboards to communicate findings to stakeholders.

---

## Dataset Description

This project used the Stack Overflow Developer Survey, a global dataset containing responses from thousands of developers about their technology usage and preferences.

Including:
* Programming languages currently used.
* Technologies developers want to use in the future.
* Databases, platforms, and frameworks.
* Developer demographics.
* Filtered and pre-processed response data.

---

## Project Objectives

* Analyze developer survey data to answer key technology adoption questions.
* Identify trends in programming languages, databases, platforms, and frameworks.
* Compare current technology usage vs. technologies developers want to learn.
* Highlight emerging technology patterns and shifts.
* Deliver insights to stakeholders to guide future technology decisions.

## Methodology

### 1. Data Cleaning & Preparation

* Removed duplicate survey responses.
* Identified and handled missing values.
* Normalized fiels for consistent analysis.
* Verified data integrity before analysis.

### 2. Exploratory Data Analysis

* Examined survey responses to identify patterns in developer preferences.
* Explored crrelations between developer demographics and technology uses.
* Compared current vs future desired technologies.

### 3. Analysis

* Queried and aggregated survey data using SQL.
* Analyzed trends across programming languages, databases, platforms, and frameworks.
* Identifiied technolhies gaining popularity among developers.

### 4. Visualization & Reporting

* Built dashboards in IBM Cognos Analytics showing current tech usage, future tech usage, and developer demographics
* Created repoerts exported as PDFs for stakeholder review
